# McAfee remnant cleanup

Detects leftover McAfee AppX packages and `C:\Program Files\McAfee`, then
optionally removes them (process kill, AppX removal, service Start=disabled,
folder delete).

## ScreenConnect

See [ScreenConnect-Commands.ps1](ScreenConnect-Commands.ps1). Prefer elevated /
Backstage. Or use ScToolLauncher (**AV offboarding / leftovers**).
