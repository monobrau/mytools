# SC Tool Launcher

The AutoHotkey v2 launcher has moved to [work_ahk](https://github.com/monobrau/work_ahk/tree/main/ScToolLauncher).

On this PC, with the repos side by side, double-click [ScToolLauncher.cmd](../ScToolLauncher.cmd). That starts `..\work_ahk\ScToolLauncher\ScToolLauncher.ahk`. The hotkey is still **Ctrl+Shift+Alt+S**.

The scripts this launcher copies stay in mytools. Linux Work Shortcuts reads the same catalog from the work_ahk copy.
